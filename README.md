Entry for the [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949) bounty on make.fun.

`main.ts` writes the one sentence a house cat would say in its own defence in the five seconds after knocking a glass off the table — no apology, no confession, just the most convincing case a cat can make for itself — to `/output/entry.txt`.

Entry:

```
Your glass parked itself in my sunbeam, rent-free, and ignored three polite warnings, so I evicted it — and that crash was the most exciting thing this table has ever done.
```

Run with Node 22: `node main.ts`.
